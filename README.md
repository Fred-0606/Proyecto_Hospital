# Proyecto Hospital

Proyecto de grado de Maestría en Ciencia de Datos para analizar y predecir estancias prolongadas en un servicio de urgencias hospitalarias de Bogotá.

El proyecto utiliza Python y Quarto, con una organización modular y un pipeline secuencial. Los datos hospitalarios no se almacenan en Git.
